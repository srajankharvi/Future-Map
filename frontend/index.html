Interview Question

"What is the difference between an array and a linked list? When would you use each?"

Your Answer

"Array stores elements in contiguous memory and has fast access by index. Linked list uses nodes with pointers, so inserting and deleting is faster. I'd use an array when I need quick lookups and a linked list when I need frequent insertions."

AI Feedback
7/10
✅

Strengths

  • Correctly identified contiguous vs. pointer-based memory
  • Good use-case reasoning for each structure
⚠️

Areas to Improve

  • Didn't mention Big-O time complexities
  • Missing: cache performance advantage of arrays
💡

Suggested Better Answer

"An array stores elements in contiguous memory, giving O(1) random access but O(n) insertion/deletion. A linked list stores elements as nodes connected by pointers — O(1) insertion/deletion at known positions, but O(n) access. Arrays also benefit from CPU cache locality. I'd use arrays for fixed-size collections needing fast lookups, and linked lists for dynamic collections with frequent insertions."
